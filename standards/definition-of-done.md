# Definition of Done

Завдання можна вважати завершеним, тільки коли виконані наведені пункти.

## Відповідність специфікації

- [ ] Виконані критерії прийняття поточного завдання зі spec.md.
- [ ] Реалізація відповідає межам і відповідальності компонентів.
- [ ] Зміни вимог або архітектури прописані в документації.

## Код і перевірки

- [ ] `make check` завершується успішно.
- [ ] Тести покривають поведінку передбачену таскою.
- [ ] Git hooks налаштовані та перевірені.

## Документація та докази

- [ ] README містить актуальні дані: команди запуску та перевірки.
- [ ] Ключові рішення описані в ADR.
- [ ] Проведено аудит реалізації специфікації, після котрого знахідки й виправлення задокументовані.
- [ ] Результати перевірок збережені разом із командами для відтворення.
- [ ] DEFENSE містить посилання на рішення, результати та відповідні коміти.

## Репозиторій

- [ ] Залежності, результати збірки та локальні секрети не потрапили до Git.
- [ ] Зміни оформлені змістовними комітами.
- [ ] Робота виконана у feature-гілці, оформлена через PR і змерджена відповідно до умов.
