# Перелік перевірок

| Перевірка    | Команда                | Успішний результат                                         | Автоматичний запуск |
| ------------ | ---------------------- | ---------------------------------------------------------- | ------------------- |
| Форматування | `npm run format:check` | Усі файли перевірені конфігурацією Prettier                | pre-commit          |
| Лінтер       | `npm run lint`         | Немає помилок і попереджень ESLint                         | pre-commit          |
| Типи         | `npm run typecheck`    | Немає помилок TypeScript                                   | pre-push            |
| Smoke-тест   | `npm test`             | /health повертає код 200 та "status": "ok"; тест проходить | pre-push            |
| Збірка       | `npm run build`        | Компіляція завершується без помилок                        | pre-push            |

## Повна Перевірка

`make check` викликає `npm run check`, який послідовно запускає форматування, лінтер, перевірку типів, тести та в самому кінці збірку.
Якщо одна стадія закінчується помилкою то наступні не запускаються.

## Виправлення помилок

- `npm run format` автоматично виправвляє форматування.
- `npm run lint:fix` виправляє порушення, котрі ESLint може автоматично виправити.
- Інші помилки фіксяться вручну, після чого перевіряються перезапуском скрипта перевірки.

## Git hooks

- `pre-commit`: це форматування та лінтер
- `pre-push`: перевірка типів, тестів та збірки
- Некоректне відпрацювання зупинає відповідну дію Git
- Хуки перевіряють всі файли, не тільки ті що йдуть в коміт
- Хуки були перевірені та перевірка була задокументована в [атрефакті](..\artifacts\pre-commit-lint-check.txt).
