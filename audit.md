# Аудит першої лабораторної

## Відповідність специфікації

Поточний каркас відповідає ЛР1:
index.ts запускає сервер, app.ts створює застосунок і реєструє /health, app.test.ts перевіряє його працездатність.

Каталог, резервування та доступ до БД запроєктовані, але їх реалізація не входить у поточний етап.

## Основні знахідки

| Знахідка | Рішення та стан |
| --- | --- |
| Тест app.test.ts потрапляв у dist | Виправлено шляхом виключенн ятестових файлів через exclude у tsconfig.json. Після очищення та збірки тестових файлів у dist немає. Конфігурація зафіксована в коміті T-0002|
| Виключення тестів зі спільного tsconfig прибрало їх із typecheck | Обмеженt рішення: Vitest виконує тести, але команда typecheck не перевіряє їхні типи.|

## Залежності

Очевидно зайвих прямих залежностей не виявлено:
- Fastify: HTTP-сервер.
- TypeScript та @types/node: компіляція й типи Node.js.
- ESLint, @eslint/js і typescript-eslint: перевірка коду.
- Prettier: форматування.
- Vitest: тести.
- Husky: Git hooks.

## Перевірка Git hook

Спроба git commit із невикористаною змінною testSmoke завершилася помилкою ESLint і кодом 1 від Husky.
