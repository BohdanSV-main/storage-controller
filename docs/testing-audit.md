## Топ-3 прогалини тестів

Stryker показав трабли, яких тести небачили.

### 1. Верхня межа числа

Тести пропускали відхилення допустимого MAX_INT32:

```diff
- value <= MAX_INT32
+ value < MAX_INT32
```

Додали перевірку прийняття MAX_INT32 та відхилення значень за межею.
Доказ: мутант №10 у reservation.limits.ts змінив статус із Survived на Killed.

### 2. Ключ ідемпотентності

Тести пропускали ключ із самих пробілів:

```diff
- idempotencyKey.trim().length === 0
+ idempotencyKey.length === 0
```

Також не помічали помилку на межі довжини:

```diff
- idempotencyKey.length > 128
+ idempotencyKey.length >= 128
```

Додали перевірки неправильного типу, порожнього ключа, пробілів та довжини 128/129 символів.

Доказ: мутанти №33, 36, 38, 39, 40 у reservation.service.ts змінили статус із Survived на Killed.

### 3. ID для скасування й видачі

Тести проходили навіть після вимкнення перевірки ID:

```diff
- if (!isPositiveInt32(reservationId)) {
+ if (false) {
```

Доказ: мутанти №59–62 і №74–77 у reservation.service.ts змінили статус із Survived на Killed.
