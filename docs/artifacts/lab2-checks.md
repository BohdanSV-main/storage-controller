## N+1 і збій БД

```powershell
npm run test:db
```
Обидва пройшли на PostgreSQL. Кількість SQL-запитів:

| Резервів | Окремий запит на кожен товар | Поточний репозиторій |
| --- | --- | --- |
| 1 | 2 | 2 |
| 25 | 26 | 2 |

Наївне читання додане лише в тест для показу N+1.
Обрив з’єднання через тестовий TCP-проксі: 200 до збою, 503 під час збою, 200 після відновлення без перезапуску застосунку. Відповідь 503 містить лише SERVICE_UNAVAILABLE та повідомлення про тимчасову недоступність сховища.
