# ADR-0006: Запуск тестів

Статус: прийнято
Дата: 05.11.2026 17:09
## Контекст і проблема
Треба unit та інтеграційні тести
Бекенд використовує TS та ESM, наявні тести написані на Vitest
## Критерії вибору

Просте налаштування, наявність моків та сумісність з стеком.

## Розглянуті варіанти

### Варіант 1: Vitest

-Переваги:
підтримує TypeScript та ESM з коробки
уже використовується в деяких тестах
має моки й засоби вимірювання покриття.
-Недоліки:
додатково потрібно визначити правильну версію coverage та мутаційного runner


### Варіант 2: Jest
- Переваги:
має моки, та інтеграцію зі Struker.
має звіти покриття
- Недоліки: 
потрібно рефакторити наявні тести та налаштувати TypeScript та ESM.


## Рішення

Залишаємо Vitest для unit та інтеграційних тестів.
Перехід на Jest не дає нам переваги, яка виправдовує перенесення тестів.
Для покриття обираємо V8

## Наслідки
- Непотрібно рефакторити наявні тести, вони залишаються.
- Для інтеграційних тестів треба налаштувати середовище

## Перевірка

Після налаштування звіт показує 100% рядків, функцій і гілок у reservation.service.ts та reservation.limits.ts.
Unit-тести запускаються без БД. Інтеграційні перевіряють роботу
